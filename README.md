# Intern Hive – Internship Listing Website

Intern Hive is a college-level web project developed to display internship opportunities provided by various companies. The website allows students to explore internships based on their academic fields such as BCA, BBA, and others.

## Technologies Used
- HTML
- CSS
- node Js

## Purpose
This website was created as part of an academic project to help students easily access and view internship opportunities relevant to their course or area of study.
